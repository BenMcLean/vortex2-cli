# Using `vortexlib` as a library

`vortexlib` is the whole tool minus the outside world. It takes and returns `bytes` and plain `dict`s, and it
**never opens a file or a MIDI port and never prints**. That makes it usable from anywhere Python runs: a web
backend, a browser via Pyodide, a test, a GUI. The `vortex` command (package `vortex_cli`) is a thin wrapper that adds
files, real MIDI ports and argument parsing. A test (`test_library_is_file_free`) keeps it that way.

Even the spec data is embedded as Python (`vortexlib/_spec_data.py`, generated by `tools/gen_data.py` from `spec/`).

Slots are 1-based everywhere in this API.

## Converting bytes

```python
import vortexlib as vl

loaded = vl.load(
	json_bytes
)  # format detected; raises DocError / FormatError with all problems
base = vl.factory(slot=3)  # or the preset read from the keytar
preset = vl.resolve(
	loaded, base
)  # JSON: omitted fields come from `base`; vw2/syx: used as is

vw2 = vl.dump(preset, "vw2")
syx = vl.dump(preset, "syx", slot=3)  # one Set message, 182 bytes
doc = vl.dump(
	preset, "json", slot=3, reference=vl.factory(3)
)  # minimal JSON: only differences from `reference`

for key, old, new in vl.diff_presets(base, preset):
	...
```

Lower level: `vl.apply_doc(base, dict) -> (Preset, slot)`, `vl.preset_to_doc(preset)`, and in `vortexlib.codec`:
`parse_message`, `build_message`, `build_get`, `from_vw2`, `to_vw2`.

`Preset` is the 171-byte body (`preset.body`), with `.name`, `.problems()` (everything unsafe to write) and equality.

## Talking to a keytar

The library speaks the protocol (spec 8.1: retry reads, settle after writes, read back to verify) over any
`Transport`, three methods that move whole SysEx messages as bytes:

```python
class Transport(Protocol):
	def send(self, data: bytes) -> None: ...  # one complete F0..F7 message
	def receive(
		self, timeout: float
	) -> bytes | None: ...  # one message, or None on timeout
	def drain(self) -> None: ...  # discard pending input


kt = vl.Keytar(my_transport, vl.Timing(settle=1.5))
current = kt.read(3)
kt.write(3, vl.resolve(loaded, current))  # verifies by reading back; raises DeviceError
```

`vortex_cli/ports.py` has a ~30-line `mido` implementation. `vl.SimKeytar` is a software keytar that implements the
measured behaviour (including dropping Gets while busy), usable as a transport in tests.

## Schema and docs

`vl.json_schema()` returns the JSON Schema; `vl.field_rows()` the field table. Both are generated from the same
field model the converter uses (`python tools/gen_docs.py` rewrites `schema/` and `docs/fields.md`).

## Errors

* `vl.DocError`: bad JSON document; `.errors` is a list of path-prefixed messages.
* `vl.FormatError`: bad binary input (size, header, structure).
* `vl.DeviceError`: no reply, or a write that did not read back.
* `vl.SlotRequired`: an output (`syx`) needs a slot nobody supplied.
